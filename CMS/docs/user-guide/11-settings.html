Settings & profile

The Settings page controls when this computer runs its automations and shows which version of the app is installed. Your profile page shows your own account details.

On this page
  1. What is on the Settings page
  2. The automation schedule (short version)
  3. App version card
  4. Your profile (User detail page)

What is on the Settings page

Click Settings in the side menu. The page starts with the line "Preferences for this installation." — these settings belong to this computer, not to your whole company. It has two parts:

PartWhat it is for
The automation schedule (the list of tasks at the top)Turn each automatic task on or off, change how often it runs, run it now, or see its history.
App version cardSee which version is installed, check for a new one and install it.

The automation schedule (short version)

The first card on the page lists the tasks this computer runs by itself, without anyone pressing a button. Each row is one task:

  • Login update — keeps marketplace logins fresh.
  • AJIO report sync, Snapdeal report sync, Flipkart report sync — download each marketplace's reports (the "master data").
  • Refill Data — fills in missing claim details.
  • Status change — updates the status of claims.
  • Auto claim — files claims automatically.

Some rows also list the accounts or marketplaces the task is about to work on. These use colours: red means work still to do, green means done, and they change while the task runs.

What each row shows and the buttons on it

ItemMeaning
Task name, with a Running labelThe label appears while the task is working.
Last-run lineOne of: "Last completed 12/10/2026, 10:02:11 am · …", "Running since …", Started … and did not finish, Last run failed — reason, or "Has not run on this machine yet". If the task is on, it ends with when it runs next, for example "· next in 40 min".
Failed 3 times in a row — it keeps retrying, but something needs fixing or skipping.The task keeps failing. Usually a login needs re-capturing. Fix the cause, or use Skip this run.
Schedule button, for example Every hour, At 10:00, At 09:00, 18:00 or Not setShows how often the task runs. Click it to choose a different interval or time.
On / Off switchTurns this one task on or off. If no schedule is set yet, switching it on first asks you to choose one.
Run nowStarts the task immediately, exactly as the schedule would. You see "<task> started" and then a success or error message.
Skip this runAppears only after a failed run. A failed task holds up the tasks after it; skipping lets the others continue. It asks you to confirm.
HistoryEvery run of this task on this computer.
Reset (top-right of the card)Puts every task back on, at its default time (logins hourly, AJIO report sync at 10:00, Refill Data at 23:00, Auto claim every 2 hours). It asks you to confirm.
… is using the browser (top-right, for example "Login update is using the browser")Another job is using the app's browser right now, so tasks wait their turn.
ImportantReset turns Auto claim back on, and Auto claim files real claims. Only reset if you want that.
TipTo stop all automations at once, use the Automations switch at the bottom of the side menu instead of turning off each task.

For a full explanation of every task, the schedule window, the History window and when to skip a run, see 10. Scheduled automations.

App version card

The App version card — "Which build this machine is running, and where it stands against the latest release." — shows your installed version and lets you update.

The status badge

A badge at the top-right of the card tells you where things stand:

BadgeMeaning
Up to dateYou have the latest version.
Checking…The app is asking whether a newer version exists.
Update availableA newer version was found and is downloading in the background. You can keep working.
DownloadingThe new version is downloading. A progress bar shows, for example "40% of 120.5 MB · 2.1 MB/s".
Ready to installThe new version is downloaded and waiting for you to install it.
Check failedThe app could not check for updates. A red message underneath says why.
Updates not available in this buildThis copy of the app cannot update itself. Use the manual download link if one is shown, or ask TrackVid for a new installer.

What else the card shows

  • Installed — your version number. Latest appears beside it when a newer version exists.
  • A red message if something went wrong.
  • "Version 0.1.21 can be downloaded and installed manually: open the download." — appears when a newer version exists and a download link is available. Use it if the automatic update keeps failing.
  • What changed — the release notes for the new version, when provided.

How to check for and install an update

  1. Open Settings and find the App version card.
  2. Click Check for updates. The button shows a spinner while checking. (It is greyed out while a download is in progress.)
  3. If a new version is found, it downloads by itself. Wait for the badge to change to Ready to install.
  4. Make sure no automation is running (the Background work panel is gone or shows everything finished).
  5. Click Restart & install 0.1.21 (the number is the new version). The app closes, installs and reopens.
NoteInstalling closes the app, so any automation running on this computer stops. Unfinished claims are picked up on the next run. If you do not install now, the update installs automatically the next time you close the app.

How to install an update by hand

  1. On the App version card, click open the download.
  2. Your browser downloads the installer. When it finishes, close TrackVid CMS.
  3. Run the downloaded installer. If Windows says Windows protected your PC, click More info then Run anyway (see Installing the app).
  4. The app reopens on the new version. Your sign-in and settings are kept.

Your profile (User detail page)

Your profile is not in the side menu. To open it:

  1. Click your initials and name at the top-right of the window.
  2. Click View profile.
  3. The User detail page opens. The top bar shows TrackVid Operations / User detail; click TrackVid Operations to go back to the Dashboard.

The page starts with "Your TrackVid account as it is stored on the server." and has a Sign out button on the right.

Your details

The first card shows your initial, your full name and email, and a Details list:

FieldMeaning
First nameYour first name in TrackVid.
Last nameYour last name in TrackVid.
EmailThe email you sign in with.
PhoneYour phone number with country code.

A grey dash (—) means that detail is not saved in TrackVid. These details cannot be edited in the desktop app; ask your TrackVid administrator to change them.

About this installation

The second card, About this installation — "What this machine is running, and whether anything newer exists." — shows:

FieldMeaning
Installed versionThe version on this computer. Give this to support when asked.
Update statusUp to date, Checking…, Version 0.1.21 found — starting download, Downloading version 0.1.21 — 40%, Version 0.1.21 downloaded — restarting to install…, or a grey message explaining why updates are unavailable.
Available versionThe newer version, while an update is in progress.
Release notesWhat changed in the new version, when provided.

Click Check for updates on this card to check straight away. When the update is downloaded, install it with Restart and install in the top bar, or from Settings → App version.

Empty state

If the page shows No user loaded — "Sign in again to see your profile details." — your sign-in details could not be read. Close and reopen the app; if it still shows, sign out and sign in again.
