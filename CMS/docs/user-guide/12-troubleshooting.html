Installing, signing in and updates

What you seeWhat it meansWhat to do
"Windows protected your PC" when running the installerThe installer is not digitally signed yet.Click More info, then Run anyway. Do this only for an installer you received from TrackVid. If nothing happens, check whether your antivirus quarantined it.
"Missing Shortcut — Windows is searching for TrackVid CMS.exe"The installed app is missing or damaged, or it was built for a different type of computer.Run the correct installer again. Most office PCs need the x64 installer (TrackVid-CMS-x64-setup.exe).
"Cannot reach the TrackVid server. Check your internet connection."The app cannot reach TrackVid.Check the internet, Wi-Fi or office firewall, then try again.
"The server took too long to respond. Please try again."The connection is slow or the server is busy.Wait a minute and try again.
"Enter a valid email address" / "Password is required"A sign-in field is empty or wrong.Fix the highlighted field. If a red box says your email or password is wrong, ask your TrackVid admin to reset your password.
"That did not save — …" on the Responsible Use agreement, or the agreement keeps coming backYour answer could not be saved, usually because you are offline.Reconnect and click Agree & Continue. Exit closes the app.
"Update required" screen with an error and Try againThe compulsory update could not download.Check the connection and press Try again. If it keeps failing, use Download x.y.z manually, close the app and run the installer.
App version card says "Check failed" or "Updates not available in this build"The update check failed, or this copy cannot update itself.Press Check for updates again, or ask TrackVid for a fresh installer.

Dashboard and syncing

What you seeWhat it meansWhat to do
"N parts of this page could not be loaded"Some figures did not load and may show a false zero.Expand the message to see the cause, then press Refresh or Sync.
"No marketplaces yet"Your company has no marketplace accounts set up in TrackVid.Ask your admin to add them in TrackVid, then click Sync.
"Synced, but N could not be refreshed — check your connection"Part of the shared data did not download.Fix the connection and press the Sync icon again.

Marketplace logins

See Login (marketplace sign-ins) for the full page.

What you seeWhat it meansWhat to do
Red strip "N logins need updating", or a number on the Login menu itemSome logins are Expired, Expiring, Rejected or were never captured.Open Login and press Update now, or Re-capture each row. Complete any OTPs.
"No … login found — the window was closed before sign-in completed."The sign-in window was closed too early.Press Re-capture and wait until the seller dashboard loads. The window usually closes by itself.
"…automatic sign-in could not finish…"Automatic sign-in got stuck on an OTP or captcha.Re-capture and type the code or captcha in the window yourself.
Account shows UnverifiedThe marketplace refused the saved password. Automations skip this account.Press Verify, enter the correct username and password, then Save and verify. Do not keep re-capturing: some marketplaces, such as Delhivery, lock the account after repeated failures.
"Signed in to …, but the server is unreachable. The login is saved on this machine — use Update…"The login was saved on this computer but not sent to TrackVid.When you are back online, press Update on that row.
Snapdeal or Flipkart sign-in waits forever for a codeThe account's OTP switch is set wrong.Turn OTP on if the account asks for a code, off if it does not.
"POBs — not synced" (AJIO) or "Slaves — not synced" (Tata CliQ)The account's extra details were not fetched.Make sure the login is Saved, then press the POBs or Slaves button.
Delhivery or Xbees: "…signs in with OAuth tokens rather than cookies, so it cannot be captured…"These marketplaces cannot be signed in by hand.Ask the TrackVid team to turn on automatic sign-in for that marketplace, or to renew the login.

Creating and filing claims

See Create claim and Manage claims.

What you seeWhat it meansWhat to do
"Video not found" after typing the Return AWBNo return video was recorded in TrackVid for that AWB.Check the AWB. Then upload a video, record one with Record, or paste a link under "or paste link". Without a video, saving gives "*Return Video is required".
Account username drop-down is emptyNo login is saved for that marketplace.Add it on the Login page.
"Minimum three images required" / "Maximum nine images allowed"Product side images must be 3 to 9 photos.Add or remove photos until there are 3 to 9.
"Please select a SKU"More than one SKU matches the AWB.Click the SKU box and pick one in "Select Seller SKU for this AWB".
AJIO: "No record found for … The report backup covers X to Y…"The lookup is set to Report, and the order is newer than the last report sync.Switch the toggle to API (needs a signed-in AJIO account), or run the AJIO report sync.
"Each image must be less than 3MB" / "Image upload failed"The photo is too large, or the connection dropped.Use a smaller photo and try again.
"Claim created. Auto claim not started."The claim is saved, but filing did not start.Do not enter it again, or it will be filed twice. Start it from Manage claims.
"No Camera Detected" / "Camera access is currently blocked"No webcam, or the app is not allowed to use it.Connect a webcam, or allow camera access for the app in Windows or macOS privacy settings and restart the app. Uploading files still works without a camera.
"Update logins first — Nothing was started."A login the action needs is not valid.Click Re-capture login, finish each sign-in, then press the action again. Accounts marked "Optional" need an OTP and can be left out.
Checkbox on a Pending claim is greyed outSomething the claim needs is missing: for example "POB ID missing", "Sub-order number missing", "No return AWB", "No evidence on this claim", or "Reached the retry limit — 3 attempts".Hover to read the reason. Import master data that has the missing value, or wait for the nightly Refill Data task. Evidence must be added to the claim.
"Evidence links are still being prepared"The video or images are still uploading.Wait a few minutes and press Refresh.
Create Ticket greyed out: "…claims run on the server for this company…"This marketplace is set to file from the TrackVid server, not this computer.Ask the TrackVid team to turn on desktop execution for that marketplace.
"Could not check where … claims run — TrackVid was unreachable"The app could not reach TrackVid.Check the internet and click Refresh.

Bulk and SPF bulk claims

See Bulk claim and SPF bulk claim (AJIO).

What you seeWhat it meansWhat to do
Bulk claim: "Missing required column(s): …"The Increff file is missing a required column.The first row must have Return Order Type, Sales Channel, Return Gate Entry AWB, QC Reason, Client SKU ID / EAN, Forward AWB Number and Forward Unit Base Price. A file can have at most 1,000 rows.
Bulk claim rows "Unmatched (no VMS record)" or "Missing / invalid: …", or Total rows shows 0No return video exists for that AWB, the QC reason or claim type is not set up, or the Sales Channel does not match an enabled marketplace.Create those claims by hand, or ask the admin to enable the marketplace or claim type. Do not upload the same report again after creating claims from it, or you will get duplicates.
SPF bulk claim: That sheet has no "POB ID" column… / That sheet has no return numbers in it…The uploaded file does not match the expected layout.Click Download template and copy your data into it.
Rows counted as "POB not on any AJIO login here"No AJIO account on this computer holds that POB.Ask the admin to run Sync POBs or add the missing AJIO login, then run again.
"Automations are switched off — switch them on to start a bulk claim."The Automations switch is off.Turn the switch back on.
"A bulk claim is already running."Only one SPF bulk claim can run at a time.Follow it in the Background work panel (bottom-right) and wait for it to finish.
Closing the window does not stop a bulk claim Filing carries on in the background. To stop it, turn the Automations switch off. The current account finishes, and the rest are not started.

Manage claims and status change

What you seeWhat it meansWhat to do
"Nothing on this tab", or a claim you expect is missingThe page opens on the last 7 days and the Pending tab.Widen the date range (for example All Time) or switch the status tab. "Every row is filtered out" means you should clear the column filters.
Status Change shows many "Not found"No login on this computer holds those AWBs.Sign in the company's other accounts on Login, then run again.
Status Change shows many "Failed"Usually a login problem.Re-capture the login and run again.
Re-Claim: "Choose which Myntra account these disputes are sent from"No Myntra account is selected.Pick the account in the toolbar drop-down. A ticket can be reopened only once.

Scheduled automations and background jobs

See Scheduled automations and Background process.

What you seeWhat it meansWhat to do
Nothing ran overnightThe app was closed, the computer was asleep, or the Automations switch was off.Keep the app open and the switch on. Missed runs happen once when the app next opens. Check Run history.
Red "Automations paused" box in the side menuLogin update could not fix every login.Click Re-capture on the Login page and sign in to the accounts named. Automations restart by themselves.
Run now: "Automations are switched off — switch them on to run this."The switch is off.Turn it on. Note that this runs every enabled task straight away, including Auto claim.
Run now: "… is using the browser — try again when it ends."Another job is using the browser.Wait for it to finish, then try again.
"Failed N times in a row" and the task keeps retryingThe task keeps failing, usually because of a login.Read the reason and fix the login, or press Skip this run to stop retrying until the task's next time.
Auto claim: "Nothing ready to file — N Pending claims still waiting on a missing account, POB ID or sub-order number."Claims are missing details.Let Refill Data run, or fill the details by hand on Manage Claims.
Refill Data: "N past the limit"Those claims were asked about 3 times with no answer.Click Reset on the chip and confirm, so they can be asked again.
"Started … and did not finish" / "Incomplete" in historyThe app was closed, or automations were switched off, during a run.Nothing to do: it runs again automatically. Avoid closing the app while tasks run.
Auto claim turned itself back onSomeone pressed Reset in Settings, which turns every task back on.Turn Auto claim off again if this computer should not use it.
"Close TrackVid CMS? … is still running"A job is still working.Choose Keep running. Quit anyway can leave a claim filed on the marketplace that TrackVid did not record, so it may be filed again.
A job shows Failed, or a red Failed count, on Background ProcessSome items failed.Open the row and read the Reason column. Fix the cause and re-run from where it was started. Download report lists exactly what failed.

Things only the TrackVid team can change

These settings are managed centrally, not in the app. Contact your TrackVid admin if one of them needs to change:

  • Whether a marketplace's claims are filed from this computer or from the TrackVid server (desktop execution).
  • Whether a marketplace uses API-based automation.
  • The master import sync time.
  • Automatic sign-in when a login expires.
  • Adding or removing marketplace accounts, and syncing AJIO POBs.

Before you contact support

  1. Note the exact message on screen, or take a screenshot.
  2. Note the app version from Settings.
  3. For a failed job, open it on Background Process and press Download report.
  4. For an update problem, open the update log and press Copy.
