SPF bulk claim (AJIO)

Raise many AJIO SPF claims at once — for returns that never reached you (NDR) or returns AJIO says were delivered but you never got (DDR) — straight from a spreadsheet.

What this tool does

On screen this tool is called NDR/DDR Bulk Claim. You upload one spreadsheet per claim type. The app reads every row (Return AWB, SKU and POB ID), works out which of your AJIO logins owns each return, signs in once per AJIO account, and files the claims one after another on this computer.

  • The run happens in the background. You can close or minimise the window and keep working.
  • Each run is saved as a job, so you can open its results later from Background Process.
  • An Excel report of the results is written as the run goes.

Where to find it

  1. Open Manage Claims from the side menu.
  2. Click the Ajio platform tab. (The button is only shown on the Ajio tab.)
  3. In the toolbar at the top, click NDR/DDR Bulk Claim. The NDR/DDR Bulk Claim window opens.
TipIf a run is already going, opening the window shows its progress instead of a blank form. You can also reopen the window from the Background work panel in the bottom-right corner (see Watching the progress).

The two claim types: NDR and DDR

The window has two upload slots. The slot you put a file in decides which claim is raised for every row in that file — the spreadsheet itself does not say it.

Slot (as shown on screen)What it says under the titleUse it when
NDR — Not Delivered ReturnsThe return never arrived. Asks AJIO to trace it, then pay out under SPF if it is lost.The return shipment never reached your warehouse.
DDR — Delivery Disputes ReturnsAJIO says it was delivered and you never received it. Asks for the POD.AJIO shows the return as delivered, but you did not receive it.

You can fill one slot or both. A week with only NDR returns is normal — leave the DDR slot empty.

NoteDo not put the same file in both slots by mistake. A row in the NDR slot is filed as NDR; the same row in the DDR slot would be filed as DDR as well.

The spreadsheet you upload

You can upload AJIO's own return report as it is, or fill in the app's template. Files must be Excel (.xlsx or .xls).

Each row needs:

ColumnNeeded?Why
Return AWBYesThe return you are claiming for. A sheet with no return numbers is refused.
POB IDYesAJIO finds a return under its POB, and the app uses the POB to pick which AJIO login files it. A sheet with no POB ID column is refused at upload.
SKU (template: Client SKU ID / EAN)YesWhich article on the return is being claimed.
RT NumberOptionalAJIO's return order number. Speeds up the search when present.
Ticket NoOptionalIf this already holds a ticket, the row is treated as Already claimed and skipped.

How to download the template

  1. In the NDR/DDR Bulk Claim window, click Download template (bottom-left).
  2. Choose where to save it. The suggested name is ajio-bulk-claim-template.xlsx in your Downloads folder.
  3. You will see the message Template saved. Open the file and fill in the columns RT Number, Return AWB, Client SKU ID / EAN and POB ID.

How to upload a file

  1. Next to the slot you want (NDR or DDR), click Upload.
  2. Pick your spreadsheet in the file window.
  3. The slot turns green and shows the file name and the number of rows read, for example returns.xlsx · 120 rows.
  4. To use a different file, click Replace. To empty the slot, click the × button next to it.
TipClosing the file window without choosing a file does nothing and shows no error.

How to file every claimable row (quick way)

Use this when you want the app to file every row it can.

  1. Make sure the Selected Proceed switch at the top of the window is off.
  2. Upload your file(s) into the NDR and/or DDR slot.
  3. Click Submit (1) or Submit (2) — the number is how many files you uploaded. The button is greyed out until at least one file is uploaded.
  4. The app sorts the rows and starts filing. A message such as Filing 85 claims appears, and a progress card appears in the window.
NoteIf nothing in the files can be filed, you will see Nothing in those files is claimable — see the breakdown. Read the skipped counts in the card to see why (see Why some rows are skipped).

How to choose rows first (Selected Proceed)

Turn on Selected Proceed when you want to see every row before anything is filed and tick only the ones you want — for example, to file a long sheet in parts.

  1. Turn on the Selected Proceed switch at the top of the window. The main button changes from Submit to Select.
  2. Upload your file(s).
  3. Click Select. Nothing is filed yet. The Select claims to file window opens, showing how many rows were read from the sheets.
  4. Check the counts at the top: Claimable (in green) and any skipped groups.
  5. Tick or untick rows. All claimable rows start ticked.
  6. Click Submit (N), where N is the number of ticked rows. Only the ticked rows are filed. Click Back to return without filing.

Ticking many rows at once

  • A range: type numbers in Rows From … to To and click Select range. This replaces the current ticks. A line such as Rows 22–45: 18 claimable selected confirms what happened.
  • The last few: type a number in Last and click Select last — for example, the last 30 claimable rows.
  • All ticks every claimable row. Clear unticks everything.
  • The box in the table header ticks or unticks every claimable row.

The footer always shows N of M claimable selected. Submit is greyed out when nothing is ticked.

TipThe sheets are read again when you press Submit. If a row stopped being claimable in between, it is not filed.

Why some rows are skipped

Before anything is filed, the app sorts each row. Rows in these groups are not filed. The counts appear in the review window and in the progress card, so you can fix the sheet and run again.

Label on screenWhat it meansHow to fix
POB not on any AJIO login hereNone of the AJIO logins on this computer lists the row's POB. The row's message reads: No AJIO login on this machine holds POB … — run "Sync POBs" in Monitor, then retry.Ask your admin to run Sync POBs in TrackVid Monitor, or add the missing AJIO login. Then run again.
No POB IDThe row's POB ID cell is empty.Fill in the POB ID in the sheet.
Already claimedThe sheet's Ticket No column already holds a ticket for this row.Nothing — it is already claimed.
Unknown claim typeThe claim type is neither NDR nor DDR.Upload the file into the correct NDR or DDR slot.
Not selectedClaimable, but you left it unticked in Selected Proceed.Run again and tick it.

Watching the progress

Inside the window

Once a run starts, a card appears under the upload slots:

  • The heading reads Filing X of Y while running, Finished when done, or Stopped if the run ended early. The AJIO accounts in use are listed on the right.
  • Job ID — the job's number (you can select and copy it). If it also says not recorded in TrackVid, the run still files but will not appear in History.
  • A progress bar.
  • The tally:
    • N filed — claims raised successfully.
    • N failed — claims that could not be filed.
    • N not claimable — AJIO said the return cannot be claimed.
    • N held (submit disabled) — only appears when final submission is switched off for testing; nothing was actually sent to AJIO for these.
  • Below a line: the skipped groups (see above).
  • An error box in red if the run stopped with an error.
  • Show report — opens the folder holding the Excel results file.

While a run is going, the upload buttons and the Selected Proceed switch are locked, and the main button shows Running…. Only one bulk claim can run at a time.

In the corner panel

The Background work panel in the bottom-right corner shows a row called NDR/DDR bulk claim · Ajio while the run is going, with the accounts, X of Y, a progress bar, and counts of successful, failed and remaining.

  • Click the panel title to collapse or expand it.
  • Click the arrows button (Show the tally and failed AWBs) to make it larger.
  • Click the open-window button (Reopen this job's window) on the row to bring the NDR/DDR Bulk Claim window back.

When the run ends, a message appears wherever you are in the app, and is kept in the notification centre:

  • NDR/DDR bulk claim finished — Job xxxxxxxx: N successful, N failed, N skipped (shown in red if anything failed, green if nothing failed).
  • NDR/DDR bulk claim stopped — Job xxxxxxxx: …reason… if it ended early.

Closing the window, stopping, and quitting the app

  • Closing the window does not stop the run. While a run is going, the close button, Run in the background and the minimise button all just hide the window. Filing carries on.
  • There is no Stop button in this window. To stop a run, switch off the Automations switch at the top of the app. The AJIO account currently being filed finishes, and the remaining accounts are not started. The run then shows Stopped with the message Stopped — Automations were switched off before every account was filed. Switch Automations back on afterwards, or nothing else will run in the background.
  • Quitting the app while it runs: you will be asked Close TrackVid CMS?. Choose Keep running (recommended), View Background Process, or Quit anyway.
ImportantDo not quit the app in the middle of a bulk run unless you must. A claim that was being filed may already exist on AJIO without the app recording it, and a later run could file it again. If the computer sleeps or the app is closed, the job may show as STALE in History.

After the run: results, report and history

Each row of the sheet ends with one of these results (in the report and in History):

ResultMeaningWhat to do
SuccessThe claim was raised. A ticket number is recorded.Nothing.
FailedThe claim could not be raised. The reason is recorded (for example Login failed: … when the AJIO account could not sign in).Read the reason, fix it (for example re-capture the login on the Login page), then upload just those rows again.
Help Center FailedA ticket was created, but the last step of filing did not finish.Check the ticket on AJIO before trying again, so you do not raise it twice.
Not ClaimableAJIO said this return cannot be claimed. The reason is recorded.Usually nothing — read the reason.
SkippedLeft out before filing (see skipped groups).Fix the sheet and run again.
Dry RunHeld — submission was switched off.Ask your admin.
PendingNot reached (for example the run stopped first).Run those rows again.

How to open the Excel report

  1. Open the NDR/DDR Bulk Claim window.
  2. In the progress card, click Show report. The folder opens with the results file selected. The file is updated after every claim, so you can open it during a run too.

How to see past runs

  1. In the NDR/DDR Bulk Claim window, click History (available at any time).
  2. The window closes and the Background Process page opens with your bulk claim jobs — counts, the AWBs that were not filed, and a downloadable report. See Background process.
